# 🏋️‍♂️ Fitness Tracker App

A simple Python desktop application to log workouts, track progress, and calculate BMI.  
Built using **Tkinter**, **Matplotlib**, and **CSV** files.

---

## 🚀 Features
- Create and edit your user profile  
- Log workouts and calculate calories burned  
- View progress summary with a live bar chart  
- Calculate BMI (auto-loads from profile)  
- Springbok Rugby–themed color palette (Green & Gold)

---

## 🛠️ Technologies Used
- Python 3.9+
- Tkinter (GUI)
- Matplotlib (Charts)
- CSV (Data Storage)
